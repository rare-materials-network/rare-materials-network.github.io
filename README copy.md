# RaRE Materials Network+ website

Static placeholder site. No build step.

## Publish on GitHub Pages
1. Upload all files in this folder to the root of a GitHub repository (keep the `assets` folder).
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Custom domain: add the .ac.uk domain under Settings > Pages, then point the DNS CNAME to `<username>.github.io`.
